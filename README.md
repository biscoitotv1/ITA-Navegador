# ITA Navegador

O ITA Navegador é um projeto de navegador web em desenvolvimento. O objetivo
é oferecer uma base simples para explorar páginas da internet, com foco em uma
experiência de navegação clara e fácil de evoluir.

## Começando

Este repositório foi iniciado como um modelo de projeto. À medida que o
navegador for implementado, mantenha o código-fonte, os recursos estáticos e
os testes organizados em diretórios próprios.

```text
ITA-Navegador/
├── README.md
├── LICENSE
└── .gitignore
```

## Contribuindo

Contribuições são bem-vindas. Antes de abrir uma alteração, descreva
claramente o comportamento proposto e inclua testes quando houver código
executável para validar.
