# Documentação do Projeto

Este diretório reúne a documentação essencial para orientar o desenvolvimento do projeto ITA-Navegador.

## Objetivo

Centralizar informações que ajudem a entender:

- o estado atual do repositório;
- o fluxo de contribuição;
- os próximos passos esperados para a evolução do projeto.

## Arquivos disponíveis

- `README.md` (raiz): visão geral e contexto principal do repositório.
- `guia-contribuicao.md`: regras básicas para trabalhar em branches, alterações e revisão de mudanças.

## Observações

Como o projeto ainda está em fase inicial, a documentação aqui presente deve ser mantida e ampliada conforme novos módulos, tecnologias e processos forem adicionados.
